4 · Your turn — speak

Three missions. Record yourself, then compare with the model answer.

1

Push back → a supplier sends an unfair clause

Reject it with object fronting: This clause __ — never front a pronoun.

“This clause we cannot accept.”🔊 Model answer — tap to compare
2

Open a status call → state your motive with focus

Use the reason-cleft: The reason I'm calling is __ — “to” or “that”, never “because”.

“The reason I'm calling is to confirm the dates.”🔊 Model answer — tap to compare
3

Say it vs. write it → you need more time

On the CALL: The thing is, __. In the EMAIL: The fact is that __.

“The thing is, we need more time.”🔊 Model answer — tap to compare
